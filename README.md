Git training repo

### Действия:

**Установи Git:**

- sudo apt install git
- git config --global user.name "Твоё имя"
- git config --global user.email "Твой email"


**Создай новый проект git-practice:**

- git init
- touch readme.md
- git add .
- git commit -m "first commit"


**Попрактикуй команды:**

- git status
- git log
- git diff
- git checkout
- git branch


Сделай по 1 мини-проекту: например, заметки в markdown, фиксация изменений.
